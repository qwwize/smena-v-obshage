# Смена в общаге

Учебный проект по курсу «Основы программирования 2» (ulearn).  
Платформа: **Windows Forms**, язык: **C#**.

## Идея игры
Игрок — дежурный по общежитию.  
За ограниченное время нужно выполнять события (поломки, поручения, уведомления) и поддерживать порядок.

## Основные механики
- Передвижение: `WASD` / стрелки
- Взаимодействие: `E`
- Пауза: `Esc`
- Перезапуск после конца игры: `R`

## Цель
Выполнить нужное количество задач до конца таймера.

## Почему игра уникальна
Это не клон классической игры.  
Собственные правила, оригинальный сеттинг и набор событий в общежитии.

## Управление
- `W`, `A`, `S`, `D` или стрелки — движение
- `E` — взаимодействие с текущим событием
- `Esc` — пауза
- `R` — рестарт

## Запуск
1. Открыть решение в Visual Studio
2. Выбрать конфигурацию Debug/Release
3. Запустить проект (`F5`)
